Der Umweg

Start und Ende sind vorgegeben. Sucht zwei Figuren aus dem Vorrat für die beiden freien Felder oben, so dass der Umweg aufgeht. Legt dann auf jeden der drei Umwegpfeile die passende Streckfaktorkarte. In das Feld auf dem direkten Pfeil schreibt ihr den Streckfaktor von Start zu Ende.
